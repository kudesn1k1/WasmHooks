# sdk/python

Python SDK WasmHooks: клиент для синхронного вызова хука из приложения оператора с дедлайном и типизированными исходами.

- Владелец: backend, Python (см. `docs/TEAM.md`).
- Потребляет: `api/invoke.openapi.yaml` (публичный Invoke API data plane).
- Реализация начинается после M0, ведёт backend, Python.
