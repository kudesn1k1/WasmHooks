# Architecture Decision Records

Список архитектурных решений. Формат — Michael Nygard (контекст, решение, отвергнутые альтернативы, последствия), плюс явный раздел «что будет означать пересмотр решения».

| ADR | Решение одной строкой |
|---|---|
| [0001](0001-sync-hooks-first.md) | Только синхронные хуки в этом семестре; асинхронная модель ложится сверху позже как ещё один тип эффекта, а не второй протокол. |
| [0002](0002-remote-service-with-thin-sdk.md) | Data plane — отдельный удалённый сервис, SDK тонкий и без бизнес-логики: вся семантика в HTTP API. |
| [0003](0003-extism-behind-sandbox-interface.md) | Extism (поверх wazero) как конкретный рантайм, но целиком спрятанный за интерфейсом `sandbox`, заменяемость которого проверяет контрактный набор `sandboxtest`. |
| [0004](0004-sans-io-scripts-effects-as-data.md) | Скрипт читает через host-функции, но не пишет: желаемые изменения мира возвращаются как данные — эффекты, которые применяет оператор или платформа. |
