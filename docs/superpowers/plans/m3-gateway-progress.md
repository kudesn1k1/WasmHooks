# M3. Контракт Invoke и допуск на gateway

Вызов с известным исходом возвращает `InvokeResponse`. При подтверждённом отказе до запуска оператор получает 503 и `X-Hook-Outcome: unavailable`. Если после отправки Execute результат потерян, оператор получает 502 с телом `application/problem+json`. Магазин в обоих случаях сохраняет покупку с нулевой скидкой. В ответе чекаута причины fallback различаются как `unavailable` и `error`.

Общий лимит gateway по умолчанию допускает 256 незавершённых вызовов, включая ожидающих квоту тенанта. Для пары тенант/хук пять последовательных ошибок гостя открывают breaker на 5 с. После cooldown проходит один пробный вызов. Успех закрывает breaker, повторная ошибка гостя открывает его ещё на 5 с. Транспортные отказы, перегрузка и таймаут из-за короткого дедлайна вызывающей стороны не засчитываются. При изменении модуля, конфига привязки или версии определения хука следующая ревизия получает отдельный breaker. Порог, cooldown и общий лимит настраиваются. Для эксперимента M2 предусмотрено отключение breaker.

Метод `gateway.Gateway.Metrics()` возвращает счётчики исходов по зарегистрированным тенантам. Квотные отказы учитываются до Execute, потерянный результат получает диагностическую метку `unknown`. Дополнительно доступны текущая загрузка gateway, число быстрых отказов breaker-а и общий счётчик для незарегистрированных идентификаторов. Смена снимка удаляет персональные счётчики выбывших тенантов.

## Проверки 23 ноября 2026

- `go test -race ./internal/gateway/... -count=1` прошёл в трёх пакетах. Тесты охватывают в том числе один конкурентный probe, новый cooldown, сброс при изменении конфига и общий лимит с ожидающими в очереди квоты.
- `go test ./internal/executor -run TestExecutorBrokenOutputSchemaIsUnavailableBeforeGuestStarts -count=1` прошёл. Изначально проверка воспроизвела исполнение гостя и его запись в лог при 503 из-за сломанной выходной схемы. Executor теперь проверяет схему до запуска.
- В `demo-shop` команда `python -m uv run --locked pytest -q` дала 53 passed. Ruff и mypy прошли. Разобранный YAML контракта содержит 502 с Problem и 503 с InvokeResponse и заголовком исхода.
- При отмене во время работы гостя исполнителю остаётся запись `unavailable/caller_canceled` с положительным временем исполнения. Если ответ можно доставить, gateway возвращает 502. До старта то же событие даёт 503. Отдельные тесты фиксируют оба HTTP-ответа и резервируют нулевое время исполнения для вызовов без старта.
