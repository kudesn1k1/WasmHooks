# Milestone 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Поднять фундамент control plane (FastAPI + PostgreSQL + MinIO) со снимком конфигурации по long-poll и подключить к нему data plane так, чтобы изменения доходили без перезапуска, а отказ control plane не останавливал вызовы; передать backend-разработчику каркас, эталонный срез и задачи.

**Architecture:** Control plane на Python хранит конфигурацию в PostgreSQL, версию снимка ведёт счётчиком в одной строке под блокировкой, отдаёт полный снимок по long-poll; ждущих будит фоновый опросчик версии. Data plane (Go) держит long-poll через `config.HTTPSource`, применяет снимки через существующий `config.Store`, берёт модули из MinIO и отвечает на Validate на отдельном внутреннем порту. Всё поднимается одним `docker compose up`, сквозной сценарий проверяет отдельный Go-модуль `e2e/`.

**Tech Stack:** Python 3.13, uv, FastAPI, pydantic v2, SQLAlchemy 2.0 Core (async, asyncpg), Alembic, pydantic-settings, PyJWT, boto3, jsonschema, httpx, pytest + pytest-asyncio + testcontainers + asgi-lifespan, ruff, mypy; Go 1.26, minio-go v7; PostgreSQL 17, MinIO; Docker Compose; GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-09-milestone-1-design.md` (далее «спек M1»). Контекст: `docs/superpowers/specs/2026-09-24-milestone-0-design.md` (спек M0), `api/dataplane-internal.openapi.yaml`, `api/invoke.openapi.yaml`.

## Review Focus

1. **Клиент обрывает long-poll** (data plane перезапускается посреди ожидания): ожидание завершается не позже `wait_s`, ничего не утекает, отмена не пишет ошибок в лог. Тест — Task 3, шаг 3.
2. **Два одновременных PUT одного хука**: ни одно изменение не теряется, `def_version` растёт на каждое изменение, обе записи в `config_changes`. Тест — Task 5, шаг 1.
3. **Внешний `$ref` в схеме хука** (`{"$ref": "https://..."}`): data plane компилирует схемы без загрузки по сети, поэтому control plane отклоняет такой хук с 422, а не пропускает в снимок. Тест — Task 5, шаг 1.
4. **Неверный внутренний токен в data plane** (401 от control plane): процесс не падает, повторяет с бэкоффом, `readyz` = 503, в логе явная причина. Тест — Task 10, шаг 1.
5. **`after_version` больше текущей версии или вне int64**: больше текущей — честное ожидание и 304; вне диапазона — 400, а не 500. Тест — Task 3, шаг 3.

```python
async def bump_config_version(conn: AsyncConnection, kind: str, payload: Mapping[str, Any]) -> int:
    """Increments the snapshot version inside the caller's transaction.

    The row lock on config_state is held until commit, so versions are handed
    out in commit order: a sequence would allocate them in insert order and a
    reader could skip a change that commits later with a lower number.
    """
    version = (
        await conn.execute(
            update(config_state)
            .where(config_state.c.id == 1)
            .values(version=config_state.c.version + 1)
            .returning(config_state.c.version)
        )
    ).scalar_one()
    await conn.execute(insert(config_changes).values(version=version, kind=kind, payload=dict(payload)))
    return version
```

```python
class VersionWatcher:
    """Tracks the snapshot version and wakes long-poll waiters when it grows.

    One background task per process polls config_state; waiters block on an
    asyncio.Event that is set and replaced on every change (the Python
    counterpart of closing a channel and making a new one). Polling works with
    several replicas and with writes that bypass the API; LISTEN/NOTIFY can be
    added later as an accelerator behind the same interface.
    """

    def __init__(self, engine: AsyncEngine, interval_s: float) -> None:
        self._engine = engine
        self._interval_s = interval_s
        self._version = 0
        self._changed = asyncio.Event()
        self._task: asyncio.Task[None] | None = None

    def current(self) -> int:
        return self._version

    async def start(self) -> None:
        self._version = await self._read()
        self._task = asyncio.create_task(self._run(), name="config-version-watcher")

    async def stop(self) -> None:
        task, self._task = self._task, None
        if task is None:
            return
        task.cancel()
        with contextlib.suppress(asyncio.CancelledError):
            await task

    async def poll_once(self) -> None:
        version = await self._read()
        if version != self._version:
            self._version = version
            changed, self._changed = self._changed, asyncio.Event()
            changed.set()

    async def wait_newer(self, after: int, timeout_s: float) -> bool:
        loop = asyncio.get_running_loop()
        deadline = loop.time() + timeout_s
        while self._version <= after:
            remaining = deadline - loop.time()
            if remaining <= 0:
                return False
            changed = self._changed
            try:
                await asyncio.wait_for(changed.wait(), remaining)
            except TimeoutError:
                return self._version > after
        return True

    async def _run(self) -> None:
        while True:
            await asyncio.sleep(self._interval_s)
            try:
                await self.poll_once()
            except Exception:
                log.exception("config version poll failed")

    async def _read(self) -> int:
        async with self._engine.connect() as conn:
            result = await conn.execute(select(config_state.c.version).where(config_state.c.id == 1))
            return int(result.scalar_one())
```

class SnapshotService:
    def __init__(self, engine: AsyncEngine, watcher: VersionWatcher) -> None:
        # One consistent read: the version and the rows it describes.
        self._engine = engine.execution_options(isolation_level="REPEATABLE READ", postgresql_readonly=True)
        self._watcher = watcher
        self._cached: tuple[int, bytes] | None = None
        self._lock = asyncio.Lock()

    async def current(self) -> tuple[int, bytes]:
        cached = self._cached
        if cached is not None and cached[0] >= self._watcher.current():
            return cached
        async with self._lock:  # single-flight: concurrent misses build once
            cached = self._cached
            if cached is not None and cached[0] >= self._watcher.current():
                return cached
            async with self._engine.begin() as conn:
                snap = await read_snapshot(conn)
            self._cached = (snap.version, snap.model_dump_json().encode())
            return self._cached

        after_version: Annotated[int | None, Query(ge=0, le=2**63 - 1)] = None,
        wait_s: Annotated[int, Query(ge=1, le=60)] = 30,
    ) -> Response:

            if not await watcher.wait_newer(after_version, wait_s):
                return Response(status_code=304)
        version, body = await snapshots.current()
        if after_version is not None and version <= after_version:
            return Response(status_code=304)
        return Response(content=body, media_type="application/json")

    return router

```go
func (p *Poller) Run(ctx context.Context) error {
	after := int64(-1)
	if cur := p.Store.Current(); cur != nil {
		after = cur.Version()
	}
	failures := 0
	for {
		snap, err := p.Source.Fetch(ctx, after)
		if ctx.Err() != nil {
			return ctx.Err()
		}
		if err == nil && snap != nil {
			err = p.Store.Update(snap)
			switch {
			case errors.Is(err, ErrStaleSnapshot):
				err = nil
			case err == nil:
				after = snap.Version
				p.Log.Info("snapshot applied", "version", snap.Version, "hooks", len(snap.Hooks), "bindings", len(snap.Bindings))
				if p.OnUpdate != nil {
					p.OnUpdate(snap)
				}
			}
		}
		if err == nil {
			failures = 0
			continue // 304 and success both go straight into the next long-poll
		}
		failures++
		wait := p.backoff(failures)
		p.Log.Error("snapshot rejected or control plane unreachable", "err", err, "retry_in", wait)
		select {
		case <-ctx.Done():
			return ctx.Err()
		case <-time.After(wait):
		}
	}
}

// backoff is exponential with full jitter: uniform in [0, min(max, min*2^(n-1))].
func (p *Poller) backoff(failures int) time.Duration {
	ceiling := p.minBackoff() << min(failures-1, 20)
	if ceiling <= 0 || ceiling > p.maxBackoff() {
		ceiling = p.maxBackoff()
	}
	return time.Duration(p.rand() * float64(ceiling))
}
```

Тест с `Rand`=1 проверяет потолок; минимальную паузу для «немедленного повтора» после успеха обеспечивает `continue` без ожидания.

```go
var checkOrder = []string{"fetch", "compile", "exports", "imports", "sample_call"}

func (e *Executor) Validate(ctx context.Context, req ValidateRequest) (ValidationReport, error) {
	select {
	case e.validateSem <- struct{}{}:
		defer func() { <-e.validateSem }()
	case <-ctx.Done():
		return ValidationReport{}, fmt.Errorf("%w: %w", ErrUnavailable, ctx.Err())
	}
	r := newReport()

	wasm, err := e.opts.Modules.Get(ctx, req.ModuleHash)
	switch {
	case errors.Is(err, modstore.ErrNotFound), errors.Is(err, modstore.ErrHashMismatch), errors.Is(err, modstore.ErrBadHash):
		return r.fail("fetch", err.Error()), nil
	case err != nil:
		return ValidationReport{}, fmt.Errorf("%w: fetch: %w", ErrUnavailable, err)
	}
	r.pass("fetch")

	spec := sandbox.ModuleSpec{
		MemoryMaxPages:       req.Hook.MemoryMaxPages,
		Timeout:              req.Hook.Timeout(),
		AllowedHostFunctions: req.Hook.AllowedHostFunctions,
	}
	mod, err := e.opts.Runtime.Compile(ctx, wasm, spec) // not e.module(): the cache is for bound modules
	var me *sandbox.ModuleError
	switch {
	case errors.As(err, &me) && len(me.Export) > 0:
		r.pass("compile")
		return r.fail("exports", strings.Join(me.Export, "; ")), nil
	case errors.As(err, &me):
		r.pass("compile")
		r.pass("exports")
		return r.fail("imports", strings.Join(me.Imports, "; ")), nil
	case errors.Is(err, sandbox.ErrInvalidModule):
		return r.fail("compile", err.Error()), nil
	case err != nil:
		return ValidationReport{}, fmt.Errorf("%w: compile: %w", ErrUnavailable, err)
	}
	defer mod.Close(context.WithoutCancel(ctx))
	r.pass("compile")
	r.pass("exports")
	r.pass("imports")

	if detail := e.sampleCall(ctx, mod, req); detail != "" {
		return r.fail("sample_call", detail), nil
	}
	return r.pass("sample_call").done(), nil
}
```

`newReport() *reportBuilder`, `(*reportBuilder).pass(name string) *reportBuilder`, `(*reportBuilder).fail(name, detail string) ValidationReport`, `(*reportBuilder).done() ValidationReport` — маленький помощник: `fail` отмечает проверку проваленной, все последующие из `checkOrder` — `ok: false, detail: "skipped"`, `OK = false`; `done` возвращает отчёт с `OK = true`. `sampleCall`: `mod.Instantiate(ctx, cfg)` (ошибка → `"instantiate: ..."`), `inst.Call` с контекстом `context.WithTimeout(ctx, req.Hook.Timeout())`, инстанс закрывается всегда; ошибки маппятся текстом исхода: `sandbox.ErrTimeout` → `"timeout after <N> ms"`, `ErrTrap`/`ErrGuest` → `"handler_error: <err>"`; успешный выход → `parseOutput(out.Output, e.opts.MaxOutputBytes, req.Hook.AllowedEffectTypes, "validate")` и `schema.Compile(req.Hook.OutputSchema)` + `Validate(result)` (не через кеш схем: определение может быть ещё не опубликовано) → ошибки как `"handler_error: <err>"`. `Options.ValidateConcurrency` (0 → 1) создаёт `validateSem` в `New`.
