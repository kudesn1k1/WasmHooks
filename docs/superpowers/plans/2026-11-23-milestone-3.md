## Журнал

- Старт. Ветка переименована по просьбе пользователя. На машине есть docker, kubectl и Go. Проверяем доступ к Docker Engine и устанавливаем kind для этой задачи.
- Раздельный запуск gateway/executor и проверка границ пакетов прошли локально. Kubernetes 1.35 по умолчанию отказался запускать kubelet на cgroup v1; выделенный кластер `wasmhooks-m3` готов на закреплённом образе 1.34.3 с kind 0.31.0. Запущены первичный сквозной прогон и проверка обратной совместимости в отдельном Compose-проекте.
- Сквозной smoke 3 → 2 → 3 прошёл после исправления тестовой Wasm-секции. Регрессия Compose прошла 9/9. Ревью выявило три случая: отмена после старта, рост истории адресов и ложноположительная проверка прогрева. Отправка после старта теперь учитывается как неизвестный результат, старые счётчики сворачиваются в общий итог, а для прогрева проверяется событие реальной компиляции без предшествующих вызовов на новом владельце. Пробный кластер удалён; итоговый эксперимент стартует с чистого стенда.

- Приёмка завершена на чистой ревизии `2818161`. 465/465 запросов, 179/179 покупок со скидками, 4/4 успешных повторов, исключение адреса за 791 мс и допуск замены за 1,405 с. В том же исходном состоянии прошли 9/9 шагов регрессионного Compose e2e. Планирование в kind восстановлено, проверочный Compose-проект удалён. [Итоговый отчёт](../../reviews/2026-11-23-m3-kind.md) · [JSON](../../reviews/m3-kind-report.json).
